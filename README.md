
# Elman vs Jordan Networks for Tiny Shakespeare

## Overview

This project compares two classical recurrent neural network architectures, Elman and Jordan Networks, on a character-level language modeling task using the Tiny Shakespeare dataset.

The main difference between the two models is their recurrent feedback mechanism:

- Elman Network uses the previous hidden state
- Jordan Network uses the previous output distribution

Both models are trained under the same settings and evaluated using loss, accuracy, perplexity, and generated text quality.
